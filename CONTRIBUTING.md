# Contributing

## Team Workflow

1. Pull `main` before starting work.
2. Create or switch to your assigned branch.
3. Make small commits with clear messages.
4. Push the branch and open a pull request.
5. Ask one teammate to review it, then merge while the demo still works.

Avoid having all four people edit the same file. Agree on simple interfaces
early: what a question looks like, what an answer looks like, and which bot
commands call which data functions.

## Definition of Done

A feature is done when it works in the shared test Discord, has a clear failure
message, and another teammate can run it from the README.
